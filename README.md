## Overview

B42 Weapon Inertia adds physically based weapon inertia and sway animation to Fallout: New Vegas, making every firearm respond to player movement, sprinting, turning, and stopping with realistic momentum-based movement. The mod works with all vanilla and modded weapons without requiring manual patching via a universal animation hook.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Fallout NV B42 Weapon Inertia** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Physical Inertia** | Weapons respond to movement with realistic momentum-based sway |
| **Sprint Reaction** | Weapon bobs and recovers realistically when sprinting and stopping |
| **Universal Compat** | Works with all vanilla and modded weapons without individual patches |
| **Animation Blend** | Inertia blends seamlessly with existing ADS and idle animations |
